## 📌 About the Project

This project explores **knee osteoarthritis detection and severity classification** from X-ray images using deep learning. A ResNet50-based transfer-learning approach is used to learn image features and classify images into severity categories.

The project is intended for educational and research purposes. It is **not a substitute for assessment by a qualified healthcare professional**.

## 📊 Result

**Reported classification accuracy: 81.2%**

*Performance depends on the dataset, class distribution, and evaluation method. This result describes the evaluated dataset and should not be interpreted as clinical validation.*

## 🌱 Future Improvements

- Evaluate performance using precision, recall, F1-score, and a confusion matrix.
- Test robustness across different X-ray sources and image quality.
